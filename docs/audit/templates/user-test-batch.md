# User Test Batch: <phase or lane>

The agent owns discovery and never blocks on a human. When a coverage row needs
proof only a person can give (physical hardware, another operating system, another
browser, audible output, a real display at a given zoom), the agent appends an item
here with everything prepared, marks the row `blocked (user batch)`, and keeps
working. The person runs the batch in one sitting and fills the result column; the
agent then converts results into evidence and row dispositions.

Rules for items in this file:

- Setup is done by the agent beforehand: fixtures staged, exact command written, the
  expected result stated so the person only observes and records.
- One item takes under five minutes. Longer checks are split.
- Items are grouped by sitting, by what the person must have in front of them, so a
  sitting never requires switching machines or devices.
- The result column takes `pass`, `fail`, or `n/a` plus one line of what was seen.
  Screenshots or recordings are optional and stay outside git.
